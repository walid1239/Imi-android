# بنية المنهاج المغربي في IMI — نسخة أولية

تاريخ الإعداد: 19 نوفمبر 2026

## نطاق البيانات

- المصدر: `data/curriculum.json`
- مجموعة Firestore: `curriculumNodes`
- الأنواع: `level`, `track`, `subject`, `unit`
- لا توجد عقد من نوع lesson ولا تُنشأ وثائق دروس ضمن seed.
- العقد التفصيلية موسومة `needsReview=true`؛ لا تمثل مصفوفة وزارية نهائية.
- الوحدات placeholders مخفية وليست أسماء وحدات رسمية.

## جدول التوثيق

| العنصر | المصدر الرسمي أو حالة المصدر | المراجعة |
|---|---|---|
| الأسلاك التعليمية الثلاثة | عرض وزارة التربية: https://pw.men.gov.ma/%D8%A7%D9%84%D8%AA%D8%B1%D8%A8%D9%8A%D8%A9-%D8%A7%D9%84%D9%88%D8%B7%D9%86%D9%8A%D8%A9 | موثق على مستوى عام |
| السنوات 1–6 ابتدائي | لم تتوفر وثيقة رسمية تفصيلية لكل سنة ضمن المصادر المفحوصة | needsReview=true |
| السنوات 1–3 إعدادي | لم تتوفر مصفوفة مواد مفصلة حسب السنة | needsReview=true |
| المسلك الدولي بالإعدادي | مدخل أولي وفق نطاق المشروع؛ يحتاج وثيقة التوجيه الخاصة به | needsReview=true |
| الجذوع المشتركة | المصدر الوزاري العام لا يثبت جميع التفاصيل والتسميات | needsReview=true |
| شعب الأولى والثانية باك | القائمة مدخلة كبنية أولية وفق طلب المشروع، وليست مصادقة وزارية | needsReview=true |
| مواد كل شعبة | غير موثّق بمصفوفة رسمية لكل (شعبة × مادة) | needsReview=true |
| لغة التدريس لكل مادة | افتراض أولي حسب توجيه المشروع، يحتاج تحققاً رسمياً | needsReview=true |
| الأسدوس وترتيب المواد | لا توجد وثيقة تفصيلية مثبتة لكل شعبة في المصادر المتاحة | needsReview=true |
| الوحدات والمحاور | أسماء الوحدات غير مدخلة؛ placeholders مخفية فقط | needsReview=true |

## المصادر الرسمية

1. وزارة التربية الوطنية — النظام التعليمي: https://pw.men.gov.ma/%D8%A7%D9%84%D8%AA%D8%B1%D8%A8%D9%8A%D8%A9-%D8%A7%D9%84%D9%88%D8%B7%D9%86%D9%8A%D8%A9
   يثبت الهيكل العام للأسلاك، ولا يوفر المصفوفة التفصيلية الكاملة.
2. اجتماع لجنة تجديد وتكييف المناهج (27 يوليو 2026):
   https://www.men.gov.ma/fr/actualites/m-le-ministre-participe-%C3%A0-la-r%C3%A9union-de-la-commission-permanente-charg%C3%A9e-du-renouvellement-et-de-l%E2%80%99adaptation-des-curricula-et-des-programmes
   يتحدث عن إطار أولي قيد النقاش، وليس مصفوفة نهائية.
3. القانون 59.21، المادة 76:
   https://pw.men.gov.ma/sites/default/files/loi59.21Enseignement-Scolaire.pdf
   يحدد مسؤولية الوزارة عن إعداد المناهج ومراجعتها، ولا يسرد كل الشعب والمواد.

## المطلوب إضافته إلى docs/curriculum-sources/

- الأطر المرجعية الحالية للامتحانات.
- التوجيهات التربوية والبرامج الرسمية لكل مادة وسلك.
- المذكرات الخاصة بالمسالك الدولية والمهنية والتعليم الأصيل.
- وثائق لغة التدريس والتوزيع السنوي والأسدوسات.

يجب تسجيل عنوان الوثيقة والجهة والتاريخ والإصدار والرابط ورقم الصفحة/القسم وربطها بالعقدة المناسبة. لا تُنسخ دروس أو كتب محمية.

## سياسة العرض

تُعرض العقد التفصيلية كهيكل مبدئي مع تنبيه واضح «قيد التحقق — ليست قائمة وزارية معتمدة». تبقى الوحدات مخفية حتى توثيق أسمائها. لا ينشر درس علمي قبل مراجعة أستاذ مختص.

## تشغيل seed

محاكي Firestore:
```bash
firebase emulators:start --only firestore --project demo-imi-curriculum
node scripts/seed-curriculum.cjs --emulator --project=demo-imi-curriculum
```

إنتاج — أمر يدوي منفصل لم يُشغّل:
```bash
node scripts/seed-curriculum.cjs --production --project=imi-indroid --confirm=imi-indroid
```

يتطلب الإنتاج Application Default Credentials وصلاحية كتابة Firestore. السكربت لا ينشر Firebase ولا يعمل تلقائياً، وهو إضافي ولا يحذف العقد القديمة.
