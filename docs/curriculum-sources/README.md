# Curriculum source drop

ضع هنا النسخ الرسمية التي تملكها أو التي تسمح الوزارة بإعادة استخدامها:
- الأطر المرجعية للامتحانات.
- التوجيهات التربوية والبرامج الرسمية.
- المذكرات الخاصة بالمسالك الدولية والمهنية والتعليم الأصيل.
- وثائق لغات التدريس والتوزيع السنوي والأسدوسات.

لا تضع كلمات مرور أو مفاتيح خدمة، ولا تنسخ دروساً أو كتباً محمية. اربط كل مادة أو وحدة بالمصدر ورقم الصفحة/القسم واطلب مراجعة أستاذ مختص.
